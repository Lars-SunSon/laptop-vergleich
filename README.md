# Laptop-Vergleich fürs Studium

Persönliche Vergleichsseite für sechs Lenovo-Notebooks (fünf Angebote von lenovo.com/de plus ein
ThinkPad als Zusatzkandidat). Eine einzige `index.html`, kein Build, kein Backend.

Kriterium: Laufzeit vor Leistung. Ranking und Begründung stammen aus der Recherche und
Lars' eigener Abwägung, nicht aus einer automatisierten Bewertung.

Live: https://lars-sunson.github.io/laptop-vergleich/
